COLORS:
  Creator card: White (#FFFFFF)
  Pro card: Yellow (#FFE75C)
  Borders: Black (#000000) - 4px thick
  Shadows: Black - 4px offset on Creator, 6px on Pro
  Text: Black (#000000) on white/yellow
  Buttons: White on Creator, Black on Pro

RESPONSIVE:
  Desktop (>768px): Side-by-side grid (2 columns)
  Mobile (<768px): Stacked vertically

INTERACTIONS:
  - Hover: Button shadow increases
  - Click: Loading spinner + "Redirecting..." text
  - Both buttons disabled during loading
  - Close: X button (top-right), Escape key, or click overlay
  - Prevents body scroll when open

DESIGN PHILOSOPHY:
  Pro is INTENTIONALLY emphasized:
  - Larger shadow (6px vs 4px)
  - Yellow highlight color
  - "Best Value" badge
  - Sparkles vs checkmarks
  - Positioned on right (primary position in LTR languages)
  - Better messaging ("all projects" vs "this book only")

  Why? Pro is objectively better value for regular users:
  - $39.99 ÷ $12.99 = ~3.08 books to break even
  - Unlocks ALL books, not just one
  - Authors publishing regularly save significantly

  However, Creator is still a valid option:
  - Single-project authors
  - Testing premium features before committing
  - One-time export needs

  The modal respects user choice while guiding toward better value.
